## 问题1：新建班级后，班级显示卡没有更新

### 问题描述
用户新建班级后，班级列表页面没有立即显示新建的班级卡片，需要手动刷新页面才能看到。

### 根本原因
1. `queryClient.invalidateQueries()` 是异步操作
2. 对话框在数据刷新完成前就关闭了
3. 没有等待查询重新获取数据

### 修复方案
在 `ClassList` 组件的 `onSuccess` 回调中：
- 使用 `await` 等待 `invalidateQueries` 完成
- 添加短暂延迟（100ms）确保UI更新
- 然后再关闭对话框

### 修复代码
```tsx
// frontend/components/dashboard/class-list.tsx
onSuccess={async () => {
  // 等待数据刷新完成
  await queryClient.invalidateQueries({ queryKey: ['classes'] });
  // 短暂延迟确保UI更新
  setTimeout(() => {
    setDialogOpen(false);
  }, 100);
}}
```

### 修复效果
✅ 新建班级后，班级卡片立即显示在列表中
✅ 用户体验流畅，无需手动刷新

## 问题2：新建班级后，还是提示要激活班级

### 问题描述
用户新建班级后，系统仍然提示"还没有激活的班级"，需要手动点击"切换到此班级"按钮才能使用。

### 根本原因
1. 后端创建班级时返回 `isActive: false`
2. 新建班级后没有自动激活
3. 用户需要额外操作才能使用新班级

### 修复方案
在 `ClassDialog` 组件的创建成功回调中：
1. 获取新建班级的ID
2. 自动调用激活API
3. 更新用户状态中的 `currentClassId`
4. 这样新建班级后立即可用

### 修复代码
```tsx
// frontend/components/dashboard/class-dialog.tsx
const createMutation = useMutation({
  mutationFn: (data: { name: string; teacherName?: string }) =>
    classesApi.create(data),
  onSuccess: async (response: any) => {
    // 新建班级后自动激活
    const newClassId = response?.data?.id;
    if (newClassId) {
      try {
        await classesApi.activate(newClassId);
        updateUser({ currentClassId: newClassId });
      } catch (error) {
        console.error('Auto activate class error:', error);
      }
    }
    onSuccess();
  },
  // ...
});
```

### 修复效果
✅ 新建班级后自动激活
✅ 用户可以立即使用新班级
✅ 无需额外点击"切换到此班级"
✅ 新班级卡片显示"当前班级"标签

## 技术细节

### 问题1的技术原因
- React Query 的 `invalidateQueries` 会标记查询为过期
- 但实际的重新获取是异步的
- 如果立即关闭对话框，用户可能看不到更新

### 问题2的技术原因
- 后端 `ClassesService.create()` 返回 `isActive: false`
- 前端没有调用激活API
- 用户状态中的 `currentClassId` 没有更新

### 修复的关键点
1. **异步等待**: 使用 `await` 确保数据刷新完成
2. **自动激活**: 新建班级后立即调用激活API
3. **状态同步**: 更新全局状态中的当前班级ID
4. **错误处理**: 激活失败时不影响班级创建

## 相关API

### 班级激活API
- **端点**: `POST /api/classes/:id/activate`
- **功能**: 将指定班级设置为当前激活班级
- **返回**: `{ id: string, isActive: true }`

### 班级创建API
- **端点**: `POST /api/classes`
- **参数**: `{ name: string, teacherName?: string }`
- **返回**: `{ id: string, name: string, isActive: false, ... }`
