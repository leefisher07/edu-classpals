## 💡 技术亮点

1. **权限控制** - 所有 API 都有严格的权限校验
2. **事务处理** - 积分操作、兑换等使用 Prisma 事务保证一致性
3. **软删除** - 班级删除采用归档方式，数据不丢失
4. **时间窗口** - 积分撤销5分钟时限精确控制
5. **批量操作** - 学生添加、积分操作支持批量处理
6. **动态计算** - 统计信息实时计算，保证准确性
7. **宠物联动** - 加分自动触发宠物经验值增长和升级
8. **家长验证** - 分享链接支持手机号验证和权限控制
9. **随机算法** - 小组分组和随机点名使用洗牌算法
