### 2.3 修复的API问题

在测试过程中发现并修复了以下8个API问题：

1. **班级创建字段名错误**
   - 问题：使用了 `headTeacher` 字段
   - 修复：改为 `teacherName` 字段

2. **学生创建字段格式错误**
   - 问题：使用了 `name` 字符串字段
   - 修复：改为 `names` 数组字段

3. **积分操作端点错误**
   - 问题：使用了 `/points/add` 和 `/points/deduct` 端点
   - 修复：统一使用 `/students/:id/points` 端点，通过 `type` 字段区分

4. **积分规则字段名错误**
   - 问题：使用了 `value` 字段
   - 修复：改为 `points` 字段

5. **商品字段名错误**
   - 问题：使用了 `pointCost` 字段，缺少 `category` 字段
   - 修复：改为 `price` 字段，添加 `category: 'PHYSICAL'`

6. **API端点路径错误**
   - 问题：多个端点使用了错误的路径结构
   - 修复：统一使用 `/classes/:classId/xxx` 嵌套路径结构

7. **排行榜端点错误**
   - 问题：使用了 `/dashboard/:classId/ranking`
   - 修复：改为 `/classes/:classId/dashboard/ranking/students`

8. **积分记录端点错误**
   - 问题：使用了 `/classes/:classId/points`
   - 修复：改为 `/classes/:classId/points/records`

**认证相关**:
- POST /api/auth/login - 用户登录
- POST /api/auth/register - 用户注册

- POST /api/classes - 创建班级
- GET /api/classes - 获取班级列表

- PATCH /api/classes/:id - 更新班级
- DELETE /api/classes/:id - 删除班级

**学生管理**:
- POST /api/classes/:classId/students - 创建学生
