## 一、优化内容

### 1.1 学生管理页面 (students/page.tsx)

**优化前**：
- 搜索框和添加按钮在同一行，可能不够明显
- 添加学生按钮样式普通

**优化后**：
- ✅ 搜索框和添加按钮分行显示，更清晰
- ✅ 搜索框添加了 `aria-label="搜索学生"` 提升可访问性
- ✅ 搜索框宽度优化为 `flex-1 max-w-md w-full`
- ✅ 添加学生按钮使用 `size="lg"` 更大更明显
- ✅ 添加学生按钮添加阴影效果 `shadow-md`
- ✅ 图标尺寸从 `w-4 h-4` 增加到 `w-5 h-5`
- ✅ 添加"快速操作："标签，提升用户理解

**代码变更**：
```tsx
// 优化后的布局
<div className="flex flex-col sm:flex-row gap-3 items-start sm:items-center">
  <div className="relative flex-1 max-w-md w-full">
    <Search className="absolute left-3 top-1/2 -translate-y-1/2 w-4 h-4 text-muted-foreground" />
    <Input
      placeholder="搜索学生姓名/学号..."
      value={searchQuery}
      onChange={(e) => setSearchQuery(e.target.value)}
      className="pl-9 h-10"
      aria-label="搜索学生"
    />
  </div>
  <Button
    onClick={() => setAddDialogOpen(true)}
    size="lg"
    className="bg-primary hover:bg-primary/90 shadow-md whitespace-nowrap"
  >
    <Plus className="w-5 h-5 mr-2" />添加学生
  </Button>
</div>
```
