## 三、后端修复详情

### 修复1：宠物图鉴权限验证（P0严重）

**问题描述：**
- 宠物图鉴的创建、更新、删除操作完全缺少权限验证
- 任何认证用户都可以修改全局宠物库
- 风险等级：**严重**

**修复文件：** `backend/src/modules/pets/pets.controller.ts`

**修复方案：**
```typescript
// 添加角色守卫和管理员权限验证
import { Roles } from '../../common/decorators/roles.decorator';
import { RolesGuard } from '../../common/guards/roles.guard';

@Controller('pets/gallery')
@UseGuards(RolesGuard)
export class PetGalleryController {

  @Post()
  @Roles('ADMIN')  // 只允许管理员创建
  createPet(@Body() dto: CreatePetDto) {
    return this.petsService.createPetGallery(dto);
  }

  @Patch(':id')
  @Roles('ADMIN')  // 只允许管理员更新
  update(@Param('id') id: string, @Body() dto: UpdatePetDto) {
    return this.petsService.updatePetGallery(id, dto);
  }

  @Delete(':id')
  @Roles('ADMIN')  // 只允许管理员删除
  remove(@Param('id') id: string) {
    return this.petsService.removePetGallery(id);
  }
}
```

**修复效果：**
- ✅ 只有管理员可以管理宠物图鉴
- ✅ 普通用户无法修改全局宠物库
- ✅ 保护了系统核心数据

**修复方案：**
```typescript
async batchPoints(userId: string, classId: string, dto: BatchPointsDto, operatorName: string) {
```

- ✅ 批量操作前验证所有学生ID归属
